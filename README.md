# 학교 AI 웹앱 — 초기 시제품

현재 저장소는 기존 앱 코드가 없는 상태에서 만든 **초기 프런트엔드·상태 확인 서버**입니다. 학생용 서비스로 배포할 수 있는 완성품이 아닙니다.

## 로컬 실행

Node.js 20 이상이 필요합니다.

```sh
npm install
npm run server
```

다른 터미널에서:

```sh
npm run dev
```

Vite가 출력한 주소로 접속하세요. `/api/status`는 백엔드 연결 상태와 제공하지 않는 기능을 명시합니다. `npm run build`는 프런트엔드를 빌드하지만 빌드 결과물만 정적으로 배포하면 `/api/status`가 없으므로 서버는 ‘연결 안 됨’으로 표시됩니다.

## 실제 구현 상태

- 완료: 반응형 화면, 서버 상태 API, 미구현 기능의 명시적 안내, 비밀 파일을 제외하는 `.gitignore`.
- 미구현: 학생별 인증·DB 격리·AI 호출·GitHub 스킬 등록·MCP 클라이언트·서비스 어댑터·자격 증명 저장·Python 샌드박스.
- **코드 실행과 임의 GitHub MCP 서버 실행은 격리·권한 검증 전까지 제공하지 않습니다.** 사용량 제한과 비용 관리도 아직 없습니다.

## 다음 개발 순서

1. 배포 환경과 인증/DB를 결정하고 서버에서 사용자별 데이터 소유권을 검증.
2. AI 도구 호출 루프와 학생별 활성화/권한 재검사 구현.
3. GitHub 스킬 파일을 커밋에 고정하고 신뢰할 수 없는 참고 자료로만 반영.
4. 검증된 MCP 커넥터/서비스 어댑터를 카탈로그에 추가하고 자격 증명은 서버 측에 안전하게 저장.
5. 네트워크·호스트 파일·비밀 접근 차단을 실제로 검증한 격리 실행 환경에서만 Python 실행을 활성화.

코드를 실행·빌드·배포해 보지 않았습니다. 테스트를 수행하지 않은 결과를 성공했다고 표시하지 않습니다. API 키나 비밀번호를 채팅이나 저장소에 올리지 마세요.
