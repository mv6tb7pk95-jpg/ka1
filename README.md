# 학교 AI 웹앱 — 개발용 MVP

학생별 계정, GitHub 스킬을 고정 커밋으로 등록·내용 확인·켜기/끄기, AI 채팅(운영자가 서버 키를 설정한 경우), 서버 계산 도구 및 학생별 도구 호출 기록을 제공합니다. **학교 운영 환경에 바로 배포할 수 있는 완성품은 아닙니다.**

## 실행

Node.js 20 이상:

```sh
npm install
npm run build
npm start
```

접속 주소: 로컬에서 `http://localhost:3000` (PORT 환경변수로 변경 가능). 개발 중에는 별도 터미널에서 `npm run dev`를 실행하고 Vite 주소로 접속합니다. Vite 프록시는 3000 포트의 서버를 가리킵니다.

운영자만 서버 환경변수 `OPENAI_API_KEY`를 지정해야 AI 답변이 작동합니다. 설정되지 않으면 AI 요청은 503 오류로 안내합니다. 대화·키를 채팅이나 저장소에 올리지 마세요. 기본 데이터 경로 `data/store.json`은 `.gitignore`로 제외되어 있습니다. 서버 재시작 시 로그인 세션은 초기화되며 데이터 파일은 유지됩니다.

배포 플랫폼에서 빌드 명령 `npm install && npm run build`, 시작 명령 `npm start`를 사용하고 영구 볼륨을 `data/`에 연결해야 계정과 스킬이 유지됩니다. 현재 배포한 주소는 **없습니다**. GitHub 저장소 URL은 웹앱 접속 URL이 아닙니다. GitHub Pages 등 정적 호스팅만으로는 서버 API가 작동하지 않습니다.

## 안전상 한계

- 인증은 기본 로컬 계정·scrypt 비밀번호 해시·24시간 메모리 세션으로 구현했습니다. 이메일 검증, 비밀번호 재설정, CSRF에 대비한 쿠키 방식, 운영자 계정 관리, 감사·백업, 실서비스 수준의 무차별 대입 방지/개인정보 정책은 아직 없습니다. HTTPS와 실제 학교 인증 연동 없이 학생 개인정보를 수집하거나 학교 운영에 사용하지 마세요.
- 학생별 스킬 조회·활성화·AI 참조는 서버에서 사용자 ID로 분리합니다. 스킬 파일은 공개 GitHub API의 고정 SHA를 통해 등록하며 자동 업데이트하지 않습니다. 신뢰할 수 없는 자료로만 전달하지만 모델이 외부 글의 악성 지시를 완벽히 무시하도록 보장할 수는 없습니다.
- AI는 서버 키가 있을 때만 동작하며 기본 모델은 `gpt-4o-mini` (`OPENAI_MODEL`로 변경). 질문·활성 스킬 내용이 AI 제공자에게 전달됩니다. 모델 도구 호출 루프는 아직 없고 계산기 API는 UI에서 직접 호출합니다.
- **미구현:** Python 격리 실행, MCP 연결·도구 탐색·실행, 임의 GitHub MCP 서버 실행, 범용 서비스 어댑터 개발자 인터페이스, 학생별 외부 서비스 자격 증명 및 비용 관리, AI의 플러그인 자동 호출. 검증된 격리 환경이나 커넥터 없이 이를 제공하지 않습니다.
- 빌드·실행·테스트·실제 배포를 이 대화 환경에서 수행할 수 없어 검증 완료라고 표시하지 않습니다. 배포 시 HTTPS, 영구 데이터베이스, 서버 키 관리, 권한 검증 테스트 및 코드 리뷰가 필요합니다.
