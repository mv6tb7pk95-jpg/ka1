# 학교 AI 웹앱 — 개발용 MVP

학생별 로컬 계정, GitHub 스킬 고정 커밋 등록·내용 확인·켜기/끄기, AI 채팅, 학생별 검증된 계산기 어댑터 활성화·비활성화 및 AI 도구 호출 루프, 학생별 도구 실행 기록을 제공합니다. **학교 운영 환경에 바로 배포할 수 있는 완성품이 아닙니다.**

## 실행

Node.js 20 이상:

```sh
npm install
npm run build
npm start
```

로컬 접속: `http://localhost:3000` (`PORT`로 변경 가능). 개발 모드는 서버와 `npm run dev`를 별도 터미널에서 실행합니다. 서버 환경변수 `OPENAI_API_KEY`가 있어야 AI 대화가 작동합니다. 기본 모델 `gpt-4o-mini` (`OPENAI_MODEL`로 변경). 키·비밀번호는 채팅이나 GitHub에 올리지 마세요. `data/store.json`은 `.gitignore` 대상이며 재시작 시 로그인 세션만 초기화됩니다.

## 이번에 추가한 부분

- `server/integrations.js`: 검증된 어댑터 카탈로그 및 공통 도구 정의·실행 인터페이스. 현재 실제 구현된 어댑터는 사칙연산 계산기 하나입니다. 새 어댑터를 추가하려면 서버 코드를 검토하고 배포해야 합니다. 사용자 제공 URL이나 코드는 실행하지 않습니다.
- 학생이 계산기를 켜거나 끄면 설정이 자기 계정에만 적용됩니다. 꺼진 도구는 AI 도구 정의에 제공되지 않고 직접 호출도 403으로 거절됩니다. 각 호출마다 인증된 세션의 사용자 ID로 권한을 다시 확인합니다.
- AI 응답은 최대 4회 왕복, 각 왕복 최대 3개 도구 호출로 제한합니다. 학생별 도구 호출 빈도도 제한합니다. 사용 기록에는 도구 이름·시각·상태만 저장하며 입력과 결과 원문은 저장하지 않습니다.
- 프런트엔드에서 학생별 플러그인 토글과 최근 도구 실행 기록을 확인할 수 있습니다. 업데이트 전 등록되지 않았던 기존 학생에게도 계산기는 기본적으로 꺼진 상태입니다.

## 중요한 제한

- **미구현:** Python 격리 샌드박스, MCP 클라이언트와 서버 연결·탐색·실행, 사용자 임의 GitHub MCP 실행, 외부 서비스 인증·자격 증명 저장 및 비용 한도, 검증된 계산기 이외의 서비스 어댑터. 배포 환경에서 격리가 검증되지 않은 Python 실행을 열지 않습니다.
- 로컬 계정·scrypt 해시·24시간 메모리 세션은 개발용입니다. 이메일 확인, 실제 학교 SSO, 비밀번호 재설정, HTTPS 운영 설정, 실서비스 수준의 로그인 방어, 백업, 개인정보 정책이 없습니다. 토큰은 sessionStorage에 저장되므로 XSS를 방지하고 실제 배포 전 인증 방식을 재검토해야 합니다.
- 단일 JSON 파일 DB는 다중 프로세스와 동시 쓰기·운영용 DB로 적합하지 않습니다. 등록된 스킬은 공개 GitHub 파일의 고정 SHA에서 가져오며 최대 3개를 대화의 신뢰할 수 없는 참고 자료로 포함합니다. 프롬프트 인젝션의 완전한 차단은 보장할 수 없습니다.
- 모델이 도구 호출을 요청할 때 최대 호출 수를 검사하지만 요청별 누적 호출·비용 상한, 스키마 검증 라이브러리, 실제 서비스 인증 만료 처리 등은 추가로 필요합니다.
- 실행·빌드·통합 테스트 및 배포는 이 대화 환경에서 수행하지 못했습니다. **현재 배포된 웹페이지 링크는 없습니다.** GitHub 저장소는 접속 가능한 웹앱 주소가 아니며 GitHub Pages만으로 서버 API는 작동하지 않습니다.
